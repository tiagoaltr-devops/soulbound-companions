# Soulbound Companions — Grimório da Alma (UI Asset Starter Pack)

Pacote de **assets originais de partida** para interface RPG moderna e item Grimório da Alma.

- `assets/soulbound/textures/item/soul_grimoire.png`: textura 16x16 do item.
- `assets/soulbound/textures/gui/grimoire/`: painéis, botões, barras, ícones e mira PNG com transparência.
- `docs/asset_contact_sheet.png`: catálogo dos assets.
- `docs/grimoire_item_preview.png`: ampliação pixel-perfect do item.
- `docs/PROMPT_CODEX_FASE_6104.md`: especificação para implementação.

**Importante:** os PNGs são recursos gráficos, não interfaces funcionais. O Codex deverá construir telas, navegação, sincronização, modelos JSON de item, traduções e lógica do comando. Os painéis precisam de renderização nine-slice. Os assets são uma base visual editável, não texturas extraídas de outros mods.

O design usa fundo escuro, bordas roxas, detalhes dourados e indicadores ciano. Verifique legibilidade e contraste dentro do Minecraft.
